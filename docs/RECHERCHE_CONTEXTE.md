# Recherche — un contexte pour VERTIGE

Constat de Martin : Dream Blast n'a pas d'histoire mais a un **contexte** (oiseaux vs cochons, des œufs à sauver, des lieux). VERTIGE n'en a aucun — le titre est un mot, les billes sont des billes, les salles s'appellent « Le Vestibule ». Ce document compare comment les références installent leur contexte sans histoire, propose 5 candidats pour VERTIGE, et recommande le plus solide.

---

## 1. Comment les références font

| Jeu | Contexte en une phrase | Mascotte | Chose à sauver | Méchant | Lieu | Où on le voit |
|---|---|---|---|---|---|---|
| **Dream Blast** | Les oiseaux rêvent chaque mois d'une aventure différente pendant leur sommeil. | Red, Bomb, Chuck | Les œufs, les autres oiseaux endormis | Les cochons (très en retrait) | Mondes de rêve à thème (cirque, espace…) | Anim d'intro de niveau, mots de combo (« Fabulous », « Awesome »), fin de niveau |
| **Royal Match** | Le roi Robert, fantasque, retape son château en ruine. | Roi Robert, Winston, Duke | Les pièces du château | Aucun vrai méchant, la ruine elle-même | Le château, pièce par pièce | Carte = plan du château qui se redécore, courtes scènes entre paliers |
| **Toon Blast** | Trois héros rendent le bonheur au royaume de Toonia. | Cooper, Wally, Bruno | Bruno (mini-jeux « Rescue Bruno »), le royaume | Pas de méchant nommé | Royaume de Toonia (carte à zones) | Anim d'intro/fin (le trio en voiture), mini-cinématiques, carte du monde |
| **Homescapes** | Austin le majordome revient sauver le manoir familial. | Austin | La maison, pièce par pièce | Aucun (tension familiale douce) | Le manoir | Liste de tâches, avant/après de la pièce, dialogues entre niveaux |
| **Angry Birds** | Les cochons ont volé les œufs, les oiseaux les poursuivent. | Red et la bande | Les œufs | Les cochons (King Pig…) | Île des oiseaux / repaire des cochons | Carte (cochons qui ricanent), plateau, fin de niveau |

**Ce qui coûte cher** : cinématiques animées (Toon Blast), personnages à multiples poses détaillées (Royal Match, Homescapes), décor entièrement repeint à chaque niveau (Homescapes).
**Ce qui coûte peu, et rapporte autant** : une carte de niveaux thématisée (recoloration + quelques props), un mot de combo qui change de texte, une mascotte à 4-5 poses réutilisées partout, un compteur visuel (œufs, pièces) plutôt qu'un texte écrit. Aucun de ces jeux n'a de dialogue long — le contexte se lit en images.

## 2. Cinq contextes candidats

### A. L'HORLOGER (mécanique / steampunk) — VERTIGE devient sous-titre ou disparaît
Une horloge géante s'est déréglée à minuit pile ; le temps tourne en boucle, il faut retendre les ressorts avant que le mécanisme n'explose.
**Pourquoi ça tourne** : le plateau est l'intérieur de l'horloge — tourner, c'est littéralement remonter le mécanisme et faire avancer l'aiguille.
**Mascotte** : Cui-Cui, coucou mécanique miniature, sort de sa porte à chaque combo.
**On sauve** : bulle = porte de coucou qui libère un oisillon-rouage ; ballon = ballon-sonde qui monte réparer l'aiguille ; pierre = rouage grippé ; ruche = distributeur d'automates ; coffre = boîte à outils.
**Méchant** : le Grand Ressort. Pendule = le vrai pendule (littéral) ; Miroir = la glace du cadran ; Ruche mère = essaim d'automates-abeilles ; Sculpteur = le tailleur de rouages ; Écho = le carillon ; Voleur = le coucou voleur.
**3 actes** : les Ateliers → le Cadran → le Cœur du Temps.
**4 persos** : le Vertige = le grand ressort qui tourne ; l'Ingénieur = l'apprenti horloger ; la Ruche = la gardienne des automates ; le Cartographe = le lecteur de plans.
**Billes** = perles de rouage, pierres d'horlogerie colorées.
**Cartoon pop** : laiton et bonbons cohabitent bien, contours épais sur engrenages ronds — fonctionne.
**Salles** : Le Vestibule → L'Antichambre à Ressorts ; Le Puits → Le Puits d'Engrenages ; Marée haute → Fuite de Vapeur.

### B. LE GRAND NID (naturel / animaux) — VERTIGE abandonné
Un nid géant reste accroché à la cime d'un arbre en pleine tempête ; le vent le fait tourner, il faut sauver ce qu'il contient avant qu'il ne se déchire.
**Pourquoi ça tourne** : le vent fait tournoyer le nid — justification simple mais un peu passive (subie, pas actionnée).
**Mascotte** : Duvet, oisillon tout rond.
**On sauve** : bulle = goutte de rosée qui libère une luciole ; ballon = graine-pissenlit qui s'envole ; pierre = gland coincé ; ruche = vraie ruche, ses abeilles ; coffre = tronc creux à glands.
**Méchant** : le Grand Corbeau. Pendule = branche qui balance ; Miroir = étang gelé ; Ruche mère = frelon géant ; Sculpteur = castor qui grignote le nid ; Écho = hibou qui répète ; Voleur = pie voleuse.
**3 actes** : la Clairière → la Mare aux Reflets → la Cime dans la Tempête.
**4 persos** : le Vertige = le vent ; l'Ingénieur = le castor bâtisseur ; la Ruche = la reine des abeilles ; le Cartographe = la chouette.
**Billes** = graines et baies colorées.
**Cartoon pop** : parfait, forêt bonbon façon Toon Blast.
**Salles** : Le Vestibule → La Clairière d'Entrée ; Le Puits → Le Terrier ; Marée haute → La Crue du Ruisseau.
**Risque** : trop proche de Dream Blast/Angry Birds (oiseaux, œufs, prédateur voleur) — le problème que ce document cherche à éviter.

### C. LA BOÎTE À RÊVES (onirique) — VERTIGE abandonné
Chaque nuit, la boîte à rêves d'un enfant s'ouvre ; il faut trier les rêves qui s'y bousculent avant le réveil, sinon ils tournent au cauchemar.
**Pourquoi ça tourne** : une main tourne la clé de la boîte à musique, ou secoue la boule à neige — justification mécanique très directe.
**Mascotte** : Songe, petite luciole en poussière d'étoile.
**On sauve** : bulle = bulle de rêve qui libère une luciole ; ballon = ballon de fête foraine qui file vers le Réveil ; pierre = cauchemar figé ; ruche = ruche à lucioles-rêves ; coffre = boîte à souvenirs.
**Méchant** : le Marchand de Sable Noir. Pendule = le métronome de la boîte à musique ; Miroir = la glace de la coiffeuse ; Ruche mère = lucioles corrompues ; Sculpteur = le sablier qui grignote le temps ; Écho = la poupée qui répète ; Voleur = le chat voleur d'étoiles.
**3 actes** : la Chambre d'Enfant → le Parc Onirique → le Ciel des Cauchemars.
**4 persos** : le Vertige = la clé qui tourne ; l'Ingénieur = le jouet mécanique réparateur ; la Ruche = la fée aux lucioles ; le Cartographe = le hibou en peluche.
**Billes** = perles de rêve lumineuses.
**Cartoon pop** : pastel, joli, mais s'éloigne du « ciel bleu et nuages » (univers plutôt nocturne) — demande un ajustement.
**Salles** : Le Vestibule → La Chambre Silencieuse ; Le Puits → Le Puits de Sommeil ; Marée haute → Marée de Sable.

### D. VERTIGE (objet du quotidien) — le titre reste, et colle enfin au sujet
Un bouton glisse dans le tambour d'une machine à laver géante ; il faut sauver ce qui traîne dans le linge avant l'essorage final.
**Pourquoi ça tourne** : le tambour tourne, littéralement, sans aucune métaphore à expliquer — un enfant comprend en une image (et « vertige » = ce qu'on ressent à regarder le linge tourner).
**Mascotte** : Bullotte, petite bulle de savon curieuse — un écho direct de l'élément « bulle » déjà dans le jeu.
**On sauve** : bulle = bulle de savon qui libère un bouton ; ballon = bulle qui monte flotter ; pierre = boule de charpie séchée ; ruche = panière à pinces à linge ; coffre = poche secrète du panier.
**Méchant** : Glouglou, le gremlin du siphon. Pendule = le battant de la porte du tambour ; Miroir = le hublot embué (deux faces) ; Ruche mère = distributeur de pinces géant ; Sculpteur = la mite qui grignote le tissu (retire des cases) ; Écho = l'essoreuse qui répète le geste ; Voleur = le chat qui vole les chaussettes sous le lit.
**3 actes** : le Panier à Linge → le Tambour → l'Étendoir sous l'Orage.
**4 persos** : le Vertige = la manette de programme ; l'Ingénieur = le petit réparateur ; la Ruche = la panière à pinces ; le Cartographe = l'étiquette de lavage (lit les symboles).
**Billes** = boutons, perles et bonbons de lessive colorés.
**Cartoon pop** : bulles rondes et pastel, contours épais — collent naturellement ; l'acte 3 (étendoir extérieur) retrouve le ciel bleu et les nuages.
**Salles** : Le Vestibule → Le Panier d'Entrée ; Le Puits → Le Siphon ; Marée haute → Essorage Express.

### E. CARROUSEL COSMIQUE (espace) — VERTIGE abandonné
Un vieux planétarium tourne sans arrêt ; il faut remettre de l'ordre dans le ciel avant que la nuit ne s'éteigne.
**Pourquoi ça tourne** : le dôme de l'observatoire pivote pour suivre les étoiles, ou un manège de planètes (orrery) tourne — justification mécanique solide.
**Mascotte** : Cosmo, petite étoile filante robotisée.
**On sauve** : bulle = bulle de nébuleuse qui libère une mini-étoile ; ballon = montgolfière-planète qui rejoint son orbite ; pierre = météorite figée ; ruche = essaim de satellites-lucioles ; coffre = capsule pleine de poussière d'étoile.
**Méchant** : Gloup, le trou noir facétieux. Pendule = le balancier de l'horloge stellaire ; Miroir = la lune à deux faces ; Ruche mère = satellites corrompus ; Sculpteur = le trou noir qui grignote des cases ; Écho = le radiotélescope qui répète ; Voleur = la comète voleuse.
**3 actes** : l'Observatoire → la Ceinture d'Astéroïdes → la Galaxie Tourbillon.
**4 persos** : le Vertige = la manivelle du planétarium ; l'Ingénieur = l'astronome bricoleur ; la Ruche = la gardienne des satellites ; le Cartographe = le dessinateur de constellations.
**Billes** = planètes et poussière cosmique colorées.
**Cartoon pop** : ciel nocturne étoilé au lieu du ciel bleu de la référence — le plus gros écart au style demandé, et le plus cher à peindre proprement (nébuleuses, halos).
**Salles** : Le Vestibule → Le Sas d'Entrée ; Le Puits → Le Puits Gravitationnel ; Marée haute → Marée de Comètes.

Le Nid score bien mais recopie presque le contexte de Dream Blast/Angry Birds (oiseaux, œufs, prédateur voleur) — exactement l'écueil que Martin pointe. VERTIGE (buanderie) l'emporte en cumulant la meilleure justification de rotation, le coût le plus bas et l'originalité la plus forte, au prix d'une extensibilité un peu plus resserrée sur 3 actes (à compenser par la variété des salles plutôt que des lieux).

## 4. Recommandation : VERTIGE, contexte « buanderie »

**Pitch** : Dans la buanderie d'une maison de poupée, un bouton de nacre glisse dans le tambour d'une machine à laver au moment où elle s'allume. Bullotte, petite bulle de savon curieuse, plonge pour le récupérer avant l'essorage — et découvre que Glouglou, le gremlin du siphon, avale tout ce qui traîne pour grossir son tourbillon. Salle après salle, il faut vider le tambour, sauver ce qui peut l'être, et refermer le clapet sur Glouglou avant la fin du cycle.

**Mascotte — Bullotte** : une bulle de savon translucide pastel, grands yeux, toujours en train de rebondir. Elle vit au bord du plateau (coin haut) : elle grossit et rit sur un gros combo, elle rétrécit et hoquette quand un coup est gâché, elle se dégonfle d'un coup et fait la moue à l'échec de la salle, elle éclate en confettis de savon à la victoire.

**Chose à sauver** : les objets perdus du linge (chaussettes dépareillées, boutons, petits jouets). Compteur visible en haut du plateau, une icône de panier avec « x/N retrouvés », qui se remplit visuellement plutôt qu'un texte.

**Méchant** : Glouglou, le gremlin du siphon — deux yeux globuleux et un sourire dans le noir du tuyau, jamais entièrement montré (il fait plus peur en silhouette, moins cher à animer).

**Ouverture en 3 écrans, sans texte long** :
1. Buanderie tranquille, panier plein ; Bullotte sort d'un tuyau en bulle, curieuse ; un bouton roule et tombe dans le tambour ouvert.
2. Le tambour est un tourbillon sombre ; deux yeux s'allument au fond ; la porte se referme dans un clin d'œil.
3. Bullotte plonge après le bouton ; flash ; on atterrit dans le tambour vu de l'intérieur — bouton « GO » en forme de bulle.

**Fin de salle / fin de run** : fin de salle, la porte du tambour s'ouvre et les objets retrouvés volent dans le panier-récompense (l'écran de choix de compétence devient « un objet à emporter du panier »). Victoire de run : plein soleil, le linge sèche dehors, Glouglou est aspiré dans le siphon en couinant. Échec de run : le panier se renverse, Glouglou glougloute de rire — « on relave tout » — et l'XP se convertit quand même en monnaie méta, cadrée comme « ce qu'on a sauvé avant de tout recommencer ».

**5 lignes de dialogue (Bullotte)** :
- (gros combo) « Wouhou, ça mousse ! »
- (rotation) « Oh là là, tout tourne, tout tourne ! »
- (plus de coups) « Oups... on relave tout ? »
- (victoire de salle) « Propre comme un sou neuf ! »
- (attente du joueur) « Alors, on tape ou on sèche ? »

**Assets à produire (phase 2)** :
- *Déjà en CC0 (Kenney)* : fonds ciel/nuages (Background Elements) pour l'acte 3 (étendoir), Particle Pack pour les bulles de savon et éclats, UI Pack pour les boutons/panneaux d'interface, formes rondes de base (Puzzle Pack) comme socle avant reskin couleur des billes.
- *À dessiner* : Bullotte (5-6 poses : idle, combo, échec, victoire, rotation), Glouglou (2-3 poses, surtout silhouette), 3 fonds d'acte (panier, tambour, étendoir), reskins des éléments existants (bouton nacré = cristal, pince à linge = ruche, poche du panier = coffre, fusée-jouet en carton = fusée dormante, hublot embué = miroir, veilleuse = lanterne, aimant à épingles = aimant), les 3 écrans d'ouverture, icônes UI du compteur de linge retrouvé.
- *Point ouvert pour Martin* : le glaçon (élément §5) ne trouve pas d'équivalent naturel en buanderie — le retravailler en « tache de calcaire séchée » (même comportement : recouvre, glisse à la rotation) ou l'assumer tel quel (un glaçon tombé du congélateur voisin, gag assumé).
